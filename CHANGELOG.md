# История изменений

## 2026-08-13

- В ленту заказов добавлены реальные названия, артикулы продавца, бренды и главные фото карточек.
- Каталог загружается через `POST /content/v2/get/cards/list` с пагинацией и кэшем на 10 минут.
- В окне деталей заказа добавлено увеличенное изображение товара.
- Лента заказов переведена на новый метод `POST /api/analytics/v1/order-feed`.
- Добавлены события `created`, `buyout` и `cancel`, причины отмены, направления доставки, модель склада и B2B-признак.
- Для хронологии order-feed используется `updatedAt`, а исходное время заказа сохраняется как `orderedAt`.
- Суммы `sellerPrice` и валюта ответа корректно преобразуются для интерфейса.
- Добавлен минутный кэш аналитики: частое обновление страницы больше не очищает ленту при ответе WB `429`.
- Исправлена воронка продаж для актуальных полей ответа WB API v3 (`openCount`, `cartCount`, `orderCount`, `buyoutCount`).
- Исправлено допустимое поле сортировки запроса воронки на `openCard`.
- Активирован второй кабинет, токен которого ранее оставался закомментирован в `.env`.
- Рабочий порт возвращён с временного `4188` на исходный `4173`.
- Создан сайт `wb_analytics` с лентой заказов FBS и статистических заказов.
- Добавлена воронка продаж: переходы в карточку, корзина, заказы и выкупы.
- Реализован единый токен на кабинет для всех категорий WB API.
- Добавлено чтение неограниченного количества кабинетов из `.env` (`WB_TOKEN_1`, `WB_TOKEN_2`, ...).
- Добавлено переключение и локальное переименование кабинетов в левом нижнем углу.
- Добавлены действия с заказами: просмотр статусов, отмена и получение стикеров.
- Добавлена универсальная API-консоль для документированных методов на официальных доменах WB.
- Добавлен безопасный демо-режим, который включается при отсутствии рабочих токенов.
- Токены скрыты от браузера, логов и Git.
