# История изменений

## 2026-08-13

- Создан сайт `wb_analytics` с лентой заказов FBS и статистических заказов.
- Добавлена воронка продаж: переходы в карточку, корзина, заказы и выкупы.
- Реализован единый токен на кабинет для всех категорий WB API.
- Добавлено чтение неограниченного количества кабинетов из `.env` (`WB_TOKEN_1`, `WB_TOKEN_2`, ...).
- Добавлено переключение и локальное переименование кабинетов в левом нижнем углу.
- Добавлены действия с заказами: просмотр статусов, отмена и получение стикеров.
- Добавлена универсальная API-консоль для документированных методов на официальных доменах WB.
- Добавлен безопасный демо-режим, который включается при отсутствии рабочих токенов.
- Токены скрыты от браузера, логов и Git.
