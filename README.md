# WB Pulse

Локальная панель продавца Wildberries. Сайт работает на вашем компьютере: сервер `server.js` ходит в API WB с токенами из `.env`, а страницы в папке `public/` показывают данные. Токен никогда не уходит в браузер. Поддерживается несколько кабинетов.

## Запуск

1. Скопируйте `.env.example` в `.env`.
2. Укажите `WB_TOKEN_1`. Для дополнительных кабинетов добавьте `WB_TOKEN_2`, `WB_TOKEN_3` и так далее, названия — в `WB_CABINET_N_NAME` (их можно менять и в интерфейсе, переименования хранятся в `data/cabinets.json`).
3. У токена должны быть включены категории «Маркетплейс», «Статистика», «Аналитика», «Цены и скидки», «Контент» и «Продвижение».
4. Запустите `npm start` и откройте `http://localhost:4173`. Нужен Node.js 20 или новее.

Без токенов сайт показывает демонстрационные данные (`WB_DEMO_MODE=true`). Тесты: `npm test`.

## Разделы

Меню слева одно на все страницы (`public/sidebar.js`). Сводка, реклама с детализацией кампании и воронка сами обновляются раз в 2 минуты, пока вкладка открыта.

| Раздел | Что показывает |
|---|---|
| **Сводка** | Главное за период в сравнении с прошлым периодом той же длины: заказы и выкупы, переходы и конверсия из воронки, расходы на рекламу и ДРР, график по дням, доли товаров, товары с просадкой на 30% и больше. |
| **Лента заказов** | Оформление, выкуп и отмена из аналитической ленты заказов (`POST /api/analytics/v1/order-feed`). |
| **Новые заказы** | Сборочные задания FBS: сборка в поставку, поставки и грузоместа, передача в доставку, стикеры (по одному на лист 58×40 мм). На пункте меню — число новых заданий. |
| **Остатки FBW / FBS** | Остатки по складам и товарам. Кнопка «История остатков» открывает изменения остатков из Google Таблицы: фильтры по складу и артикулу, график суммы и линии складов. |
| **Возвраты** | Возвраты покупателей. |
| **Цены и скидки** | Цены всех товаров кабинета с фильтрами, сохранёнными наборами и изменением цен. |
| **Воронка** | Воронка продаж v3 по товарам. Стрелка у товара открывает **детализацию товара** (`product.html`): органика и реклама по дням, мини-графики, флажки запуска и остановки рекламы (кликабельные; с начала отслеживания в Google Таблице — по статусу и составу кампании, раньше — по 50 показам в день), флажки изменения цены из Google Таблицы, свои отметки. |
| **Оценки товаров** | Рейтинг продавца и товаров, число отзывов по звёздам и их динамика за период. |
| **Реклама** | Расходы и рекламная выручка по дням, CTR, CPC, CPM, CR, ДРР, ROAS, кампании с числом активных артикулов. Кампания открывается в **детализации кампании** (`campaign.html`): мини-графики, товары, ключевые слова с исключением (фильтр «Все / Активные / Исключённые»), переименование, заметки, кнопка «История» (изменения из Google Таблицы). |
| **Дела** | Список задач: тип, приоритет, кабинет, артикул, архив и журнал по каждой задаче. |
| **История изменений** | Все изменения из Google Таблицы за период: цены, кампании, ставки, минус-фразы, остатки. Фильтры по разделу, виду изменения и кабинету и поиск. Кампании и товары — ссылками на их детализацию. |

Период во вкладке «Реклама» и рекламы в сводке — не больше 31 дня: это ограничение WB API.

## Google Таблица

Таблица сама раз в час берёт из API WB цены, кампании, ставки, минус-фразы и остатки и записывает каждое изменение в историю. Подключение и листы описаны в [google-sheets/README.md](google-sheets/README.md).

Сайт читает историю через веб-приложение скрипта: `WB_SHEET_URL` и `WB_SHEET_KEY` в `.env`. Копия истории хранится на компьютере в `data/Sheet/` (по разделам и месяцам) и дозагружается через 20 секунд после запуска сервера, раз в час и при открытии окна истории. Окна истории и раздел «История изменений» сначала показывают копию с компьютера, потом новые строки из таблицы.

## Данные на компьютере

Всё лежит в `data/` и не попадает в git:

- `cabinets.json`, `balance-history.json` — названия кабинетов и история баланса;
- `price-presets.json`, `stock-presets.json`, `keyword-tags.json` — сохранённые наборы и метки;
- `campaign-notes.json`, `product-notes.json`, `todos.json` — заметки и дела;
- `Ads/`, `Funnel/`, `Photos/` — кэш рекламной статистики, воронки и фото;
- `Sheet/` — копия Google Таблицы.

## Изменяющие действия

Сайт может менять данные в WB: цены, остатки FBS, поставки и грузоместа, исключение ключевых слов, название кампании. Каждое такое действие требует явного подтверждения в интерфейсе.
