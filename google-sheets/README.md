# Google Таблица: цены и реклама WB

Таблица сама берёт из API Wildberries цены и скидки всех товаров и статусы всех рекламных кампаний. Она обновляется раз в час и по кнопке, а каждое изменение записывает на лист «История». Скрипт работает внутри таблицы, поэтому компьютер с сайтом для этого не нужен.

## Подключение (один раз, ~5 минут)

1. Создайте новую Google Таблицу.
2. Откройте **Расширения → Apps Script**.
3. Удалите всё в файле `Код.gs` и вставьте содержимое файла [`wb-sheets.gs`](wb-sheets.gs). Нажмите **Сохранить** (значок дискеты).
4. Вернитесь на вкладку с таблицей и обновите страницу (F5). Через несколько секунд в меню появится пункт **WB**.
5. **WB → Добавить кабинет (токен)**: введите название кабинета и токен API.
   - Токен создаётся в личном кабинете WB: **Настройки → Доступ к API**.
   - Нужны категории **«Цены и скидки»**, **«Продвижение»** и **«Контент»**. Достаточно режима «Только на чтение».
   - Google при первом запуске попросит разрешения: доступ к этой таблице и к внешним сайтам (API WB). Нажмите «Разрешить». Если Google пишет «Приложение не проверено», нажмите «Дополнительно → Перейти на страницу…»: это ваш собственный скрипт.
   - Несколько кабинетов добавляются так же, по одному.
6. **WB → Обновить сейчас**: появятся листы с данными.
7. **WB → Включить обновление раз в час**: дальше таблица обновляется сама, даже закрытая.

## Листы

| Лист | Что на нём |
|---|---|
| **Цены** | Каждый товар: кабинет, артикул WB, артикул продавца, название, цена до скидки, скидка продавца, цена со скидкой, скидка WB Клуба, цена в WB Клубе. Если у размеров разные цены, они перечислены в столбце «Цены по размерам». |
| **Реклама** | Каждая кампания: ID, название, статус (активна, на паузе, готова к запуску, завершена, отменена), ставка (единая или ручная), оплата (за показы или за клики), где показывается, сколько в ней товаров, **артикулы WB** и **артикулы продавца** этих товаров (через запятую, в одном порядке), даты создания, запуска и изменения. |
| **Ставки** | Строка на пару «кампания + артикул»: кампания, статус, тип ставки, артикул WB, артикул продавца, предмет, ставка в поиске и в рекомендациях, ₽. Пустая ячейка — место показа выключено. Только кампании, которые могут показываться: активные, на паузе и готовые к запуску. |
| **Минус-фразы** | Строка на пару «кампания + артикул»: сколько поисковых запросов исключено и какие именно. Только кампании, которые могут показываться. |
| **Остатки** | Строка на «тип (FBW / FBS) + склад + артикул»: остаток в штуках, размеры сложены. Нулевые остатки не пишутся. Данные — те же отчёты WB, что у вкладок «Остатки FBW / FBS» на сайте. Если WB отдаёт склады WB одной строкой «Склад WB», так и будет. |
| **История остатков** | Строка на каждое изменение остатка: когда, кабинет, тип, артикул, товар, склад, было и стало (шт). Если остаток появился — «было 0», если закончился — «стало 0». Лист отдельный, потому что остатки меняются с каждым заказом и вытеснили бы остальную историю. Хранится до 100 000 строк. Отсюда берёт данные окно «История остатков» на сайте. |
| **История** | Строка на каждое изменение с прошлого обновления: цена, скидка, статус кампании, название, тип ставки, места показа, ставки по артикулам (раздел «Ставки», в подписи — кампания и артикул), исключённые запросы (раздел «Ключевые слова»: «исключён «запрос»» или «возвращён в работу «запрос»», в «Было / Стало» — число исключённых), состав кампании (в «Что изменилось» — «Артикулы WB: убран … , добавлен …», в «Было» и «Стало» — списки артикулов целиком). Ещё сюда попадают товары и кампании, которые появились в списке или пропали из него. Новые записи сверху. |
| **Журнал обновлений** | Когда было обновление и что WB вернул по каждому кабинету: сколько товаров и кампаний или какая ошибка. |

Листы «Цены» и «Реклама» перезаписываются при каждом обновлении. Свои столбцы и пометки лучше вести на отдельном листе, например через `=ВПР()` по артикулу. Если WB ответил ошибкой по какому-то кабинету, строки этого кабинета остаются прежними и не стираются.

## Связь с сайтом WB Pulse

Сайт берёт из «Истории» таблицы график цены (окно товара в «Ценах и скидках») и историю статуса и ставок («Детализация кампании → Размещение и ставки → История»). Для этого скрипт развёрнут как веб-приложение: «выполнять от моего имени», доступ «все». Без ключа оно ничего не отдаёт.

1. В таблице нажмите **WB → Ключ для сайта** и скопируйте строку `WB_SHEET_KEY=…`.
2. Впишите её в файл `.env` сайта рядом с `WB_SHEET_URL=https://script.google.com/macros/s/<развёртывание>/exec` и перезапустите сервер.

После правок скрипта развёртывание нужно обновить, иначе веб-приложение отдаёт старую версию: `clasp push --force`, затем `clasp update-deployment <ID развёртывания>`. ID показывает `clasp list-deployments`. Адрес при этом не меняется.

## Важно

- **Токен** хранится в настройках скрипта, а не в ячейках. Его может увидеть любой, у кого есть право **редактировать** таблицу. Другим людям давайте только доступ на просмотр.
- **Лимиты.** WB ограничивает число запросов, и для некоторых типов токенов список кампаний доступен лишь раз в час. Если в «Журнале» ошибка 429, просто подождите следующего обновления.
- **СПП** в таблице пока нет: в официальном API продавца её нет. Как её получать, обсудим отдельно.
- **Время** на листах показано в часовом поясе таблицы: **Файл → Настройки → Часовой пояс**.
- **Новая версия скрипта.** Чтобы обновить скрипт, замените код в Apps Script на новый `wb-sheets.gs` и сохраните. Можно и без копирования, через [clasp](https://github.com/google/clasp):
  1. Один раз создайте в этой папке файл `.clasp.json`: `{"scriptId":"<идентификатор скрипта>","rootDir":"."}`. Идентификатор есть в Apps Script: **⚙ Настройки проекта → Идентификатор скрипта**. Файл в `.gitignore`, у каждого свой.
  2. Каждый раз запускайте `clasp push --force` из папки `google-sheets`. В проект уходят только `wb-sheets.gs` и `appsscript.json` (см. `.claspignore`). Остальные файлы проекта Apps Script **заменяются**.

  Нужен вход `clasp login` и включённый Apps Script API: https://script.google.com/home/usersettings. Если в новой версии изменились столбцы, первое обновление просто перезапишет листы. Записей в «Истории» оно не создаст, сравнение начнётся со следующего обновления.
- Удалить кабинет: **WB → Удалить кабинет**. Выключить обновление по расписанию: **WB → Выключить автообновление**.
