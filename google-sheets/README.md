# Google Таблица: цены и реклама WB

Таблица сама берёт из API Wildberries цены и скидки всех товаров и статусы всех рекламных кампаний. Она обновляется раз в час и по кнопке, а каждое изменение записывает на лист «История». Скрипт работает внутри таблицы, поэтому компьютер с сайтом для этого не нужен.

## Подключение (один раз, ~5 минут)

1. Создайте новую Google Таблицу.
2. Откройте **Расширения → Apps Script**.
3. Удалите всё в файле `Код.gs` и вставьте содержимое файла [`wb-sheets.gs`](wb-sheets.gs). Нажмите **Сохранить** (значок дискеты).
4. Вернитесь на вкладку с таблицей и обновите страницу (F5). Через несколько секунд в меню появится пункт **WB**.
5. **WB → Добавить кабинет (токен)**: введите название кабинета и токен API.
   - Токен создаётся в личном кабинете WB: **Настройки → Доступ к API**.
   - Нужны категории **«Цены и скидки»**, **«Продвижение»** и **«Контент»**. Достаточно режима «Только на чтение».
   - Google при первом запуске попросит разрешения: доступ к этой таблице и к внешним сайтам (API WB). Нажмите «Разрешить». Если Google пишет «Приложение не проверено», нажмите «Дополнительно → Перейти на страницу…»: это ваш собственный скрипт.
   - Несколько кабинетов добавляются так же, по одному.
6. **WB → Обновить сейчас**: появятся листы с данными.
7. **WB → Включить обновление раз в час**: дальше таблица обновляется сама, даже закрытая.

## Листы

| Лист | Что на нём |
|---|---|
| **Цены** | Каждый товар: кабинет, артикул WB, артикул продавца, название, цена до скидки, скидка продавца, цена со скидкой, скидка WB Клуба, цена в WB Клубе. Если у размеров разные цены, они перечислены в столбце «Цены по размерам». |
| **Реклама** | Каждая кампания: ID, название, статус (активна, на паузе, готова к запуску, завершена, отменена), ставка (единая или ручная), оплата (за показы или за клики), где показывается, сколько в ней товаров, даты создания, запуска и изменения. |
| **История** | Строка на каждое изменение с прошлого обновления: цена, скидка, статус кампании, название, ставка, места показа, число товаров. Ещё сюда попадают товары и кампании, которые появились в списке или пропали из него. Новые записи сверху. |
| **Журнал обновлений** | Когда было обновление и что WB вернул по каждому кабинету: сколько товаров и кампаний или какая ошибка. |

Листы «Цены» и «Реклама» перезаписываются при каждом обновлении. Свои столбцы и пометки лучше вести на отдельном листе, например через `=ВПР()` по артикулу. Если WB ответил ошибкой по какому-то кабинету, строки этого кабинета остаются прежними и не стираются.

## Важно

- **Токен** хранится в настройках скрипта, а не в ячейках. Его может увидеть любой, у кого есть право **редактировать** таблицу. Другим людям давайте только доступ на просмотр.
- **Лимиты.** WB ограничивает число запросов, и для некоторых типов токенов список кампаний доступен лишь раз в час. Если в «Журнале» ошибка 429, просто подождите следующего обновления.
- **СПП** в таблице пока нет: в официальном API продавца её нет. Как её получать, обсудим отдельно.
- **Время** на листах показано в часовом поясе таблицы: **Файл → Настройки → Часовой пояс**.
- Удалить кабинет: **WB → Удалить кабинет**. Выключить обновление по расписанию: **WB → Выключить автообновление**.
