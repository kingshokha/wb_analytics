# Google Таблица: оптовые цены Сималенда

Отдельная таблица, не связанная с таблицей WB. Раз в час в неё записываются цены артикулов из вашего списка, а каждое изменение попадает на лист «История». Сайт WB Pulse показывает эту историю в разделе **«Цены Сималенда»**.

**Цены загружает компьютер с сайтом, а не сама таблица.** Сималенд не пускает запросы с серверов Google: из Apps Script любой адрес sima-land.ru, даже `robots.txt`, отвечает «Адрес недоступен» (проверено 10.11.2026). Поэтому сервер сайта раз в час делает так:
1. берёт из таблицы список артикулов;
2. запрашивает цены в API Сималенда со своего компьютера;
3. отправляет их в таблицу.

Сравнивает цены и пишет «Историю» сама таблица. **Пока компьютер с сайтом выключен, цены не обновляются**: пропущенные часы не восстанавливаются, изменение просто запишется при следующем обновлении.

## Подключение (один раз)

1. Создайте новую Google Таблицу, откройте **Расширения → Apps Script**, замените код в `Код.gs` содержимым [`sima-sheets.gs`](sima-sheets.gs) и сохраните. Можно и через clasp, см. ниже.
2. Разверните скрипт как веб-приложение: «выполнять от моего имени», доступ «все». Без ключа оно ничего не отдаёт и не принимает.
3. Обновите вкладку с таблицей (F5). Появятся меню **Сималенд** и лист **«Артикулы»**. Нажмите **Сималенд → Ключ для сайта**: Google попросит разрешения, нажмите «Разрешить». Если он пишет «Приложение не проверено», нажмите «Дополнительно → Перейти на страницу…»: это ваш собственный скрипт.
4. Впишите в `.env` сайта две строки и перезапустите сервер:
   - `SIMA_SHEET_URL=https://script.google.com/macros/s/<развёртывание>/exec`;
   - `SIMA_SHEET_KEY=…` — ключ из окна «Ключ для сайта».
5. Впишите артикулы Сималенда на лист «Артикулы»: **столбец A, со второй строки**, по одному в ячейке. Столбец B и следующие — для ваших заметок, скрипт их не читает. Новые артикулы просто дописывайте ниже, повторы и пустые строки не мешают.
6. На сайте в разделе «Цены Сималенда» нажмите **«Загрузить цены сейчас»** или подождите до часа. 6 000 артикулов загружаются примерно за 40 секунд.
7. Необязательно: впишите в `.env` строку `SIMA_TOKEN=…`. Без токена цены такие, какие Сималенд показывает покупателю без входа. С токеном это цены для вашего аккаунта. Токен создаётся на https://www.sima-land.ru/cabinet/token/ и действует год.

## Листы

| Лист | Что на нём |
|---|---|
| **Артикулы** | Ваш список, его ведёте вы. Скрипт читает только столбец A. Значения, не похожие на артикул (буквы, дроби), пропускаются, их число пишется в «Журнал обновлений». |
| **Цены** | Строка на каждый артикул из списка: артикул, товар, **цена**, **цена по акции «Опт»**, наличие (в наличии / нет в наличии / нет на Сималенде) и время обновления. Перезаписывается при каждом обновлении. Пустая цена значит, что Сималенд цены не дал: у части товаров без остатка он отдаёт 0. |
| **История** | Строка на каждое изменение: когда, артикул, товар, что изменилось, было, стало. Записываются изменения цены и цены по акции «Опт», а ещё «Добавлен в список», «Убран из списка артикулов», «Нет на Сималенде» (товара больше нет в ответе API: удалён или отключён) и «Снова есть на Сималенде». Новые строки сверху. **Старые строки не удаляются.** |
| **Журнал обновлений** | Когда было обновление: сколько артикулов, сколько изменений и какие были ошибки. |

Первое обновление только заполняет «Цены», записей в «Историю» оно не создаёт: сравнивать не с чем. Если Сималенд не ответил по какой-то сотне артикулов, их строки остаются прежними до следующего часа, а ошибка попадает в журнал. Меню **Сималенд → Как обновляются цены** показывает последнее обновление.

## Связь с сайтом WB Pulse

Веб-приложение скрипта:
- отдаёт сайту список артикулов (`GET ?articles=1`);
- принимает от него цены (`POST`);
- отдаёт «Историю» для копии на компьютере (`GET ?sync=1`).

Все запросы идут только с ключом.

**Копия на компьютере.** Сервер сайта держит копию всей «Истории»: `data/Sima/История/<ГГГГ-ММ>.json`.
- В `data/Sima/sync.json` записано, до какого момента скачано и что таблица сказала о последнем обновлении.
- В `data/Sima/refresh.json` лежит итог последней загрузки цен.

Цены загружаются через минуту после запуска сервера (если таблица не обновлялась последние 50 минут), дальше раз в час и по кнопке. После каждой загрузки дозагружается «История». Повторы отбрасываются, в копии хранится всё. Папка `data/Sima/` в `.gitignore`.

## Важно

- **API Сималенда.** Запросы идут по 100 артикулов (больше API в одном запросе не отдаёт), до 5 запросов за раз с паузой в секунду. Это ниже лимита Сималенда в 250 запросов за 10 секунд.
- **Размер таблицы.** В Google Таблице не больше 10 миллионов ячеек. В «Истории» 6 столбцов, то есть около 1,6 миллиона строк. Если цены меняются часто и лист приближается к пределу, решим вместе, куда переносить старые строки. Сами по себе они не удаляются.
- **Время** на листах показано в часовом поясе таблицы (в скрипте — Душанбе): **Файл → Настройки → Часовой пояс**.
- **Новая версия скрипта** — через [clasp](https://github.com/google/clasp) из этой папки:
  1. Один раз создайте здесь файл `.clasp.json`: `{"scriptId":"<идентификатор скрипта>","rootDir":"."}`. Идентификатор есть в Apps Script: **⚙ Настройки проекта → Идентификатор скрипта**. Файл в `.gitignore`. **Без него clasp возьмёт `.clasp.json` из папки выше, то есть проект таблицы WB, и `clasp push` заменит её скрипт.**
  2. `clasp push --force` из папки `google-sheets/sima-land`. В проект уходят только `sima-sheets.gs` и `appsscript.json` (см. `.claspignore`), остальные файлы проекта **заменяются**.
  3. Обновите развёртывание, иначе веб-приложение работает на старой версии: `clasp update-deployment <ID развёртывания>`. ID показывает `clasp list-deployments`, адрес при этом не меняется.
